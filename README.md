# RODMAN Coffee

Сайт кофейни RODMAN Coffee — Пятигорск, проспект Кирова, 87А.

Статический сайт без сборки: `index.html`, `css/style.css`, `js/main.js`.
Анимации — GSAP + ScrollTrigger, плавный скролл — Lenis (подключены с CDN).

## Как обновить меню

Позиции, цены, варианты «С кем вы сегодня?» и отзывы лежат в [`js/data.js`](js/data.js).

## Локальный запуск

```bash
python3 -m http.server 5173
```

и открыть http://localhost:5173
